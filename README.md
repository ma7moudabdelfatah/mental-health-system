# الأمانة العامة للصحة النفسية وعلاج الإدمان — نظام المترددين

نظام رسمي لمتابعة أعداد المترددين شهرياً من كل مستشفى مع التجميع في الحساب الرئيسي + التقارير والرسوم البيانية.

## المميزات
- تسجيل دخول + إنشاء حسابات (رئيسي / مستشفى)
- صفحة صلاحيات للتحكم في ظهور الصفحات
- تسجيل المترددين شهرياً لكل مستشفى
- تقارير مجمعة + جدول المستشفيات × الأشهر + رسوم Chart.js + تصدير CSV/طباعة

## التشغيل محلياً
افتح `index.html` مباشرة.

## حسابات للتجربة
- الرئيسي: `admin / admin123`
- مستشفى العباسية: `abbasiya / 123`
- مستشفى حلوان: `helwan / 123`
